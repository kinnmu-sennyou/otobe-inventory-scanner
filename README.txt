QR棚卸カメラスキャナー GitHub Pages用

ファイル一式をGitHubリポジトリの直下へアップロードします。

推奨リポジトリ名：otobe-inventory-scanner

1. index.html / style.css / app.js / config.js をアップロード
2. Settings → Pages
3. Build and deployment の Source を Deploy from a branch
4. Branch を main、Folder を /(root) にして Save
5. 公開されたURLを携帯で開く
6. 「カメラを起動」を押し、カメラ使用を許可

config.jsには現在のApps Script URLを設定済みです。
管理用PINや棚卸データはGitHubへ置いていません。
